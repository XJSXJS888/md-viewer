MD Viewer 1.1.0

Windows 下的 Markdown 阅读与编辑工具。

启动
----
双击 MDViewer.exe。首次启动会先解压到临时目录，通常需要几秒。
之后可以把这个 exe 移动到任意文件夹。

使用
----
- 点击「打开」，或按 Ctrl + O
- 把 .md / .markdown 文件拖进窗口
- 在右上角切换「阅读」和「编辑」
- 编辑后按 Ctrl + S 保存
- 也可以在命令行中打开：
  MDViewer.exe "C:\某个目录\文件.md"

快捷键
------
Ctrl + O        打开文件
Ctrl + S        保存
Ctrl + R / F5   重新加载
Ctrl + F        在阅读模式中查找
Ctrl + B        阅读模式：目录；编辑模式：加粗
Ctrl + I        编辑模式：斜体
Ctrl + + / -    调整字号
Ctrl + 0        恢复默认字号
Esc             关闭查找或目录

说明
----
- 支持 GFM 表格、任务列表、引用、代码高亮和相对路径图片。
- 支持 UTF-8、UTF-16、GB18030、Big5；保存时保留原编码和换行符。
- 文件被外部修改后会自动刷新；有未保存内容时暂停刷新。
- 关闭或切换文件前会提示保存。
- 最近打开记录和窗口大小保存在 %APPDATA%\MD Viewer\viewer-state.json。
- 程序未签名，Windows SmartScreen 首次运行可能提示；选择「更多信息 → 仍要运行」。
